# AI Interactive Sales Dashboard

Interactive sales analytics dashboard built with Google AI Studio using apparel order data.

## Overview

The application visualizes sales and order data through interactive KPI cards, charts, filters, and data tables.

The dashboard was created as part of a Google AI / Kyiv School of Economics learning lab focused on building interactive applications with AI.

## Key Features

* Executive KPI overview
* Sales trends over time
* Product performance analysis
* Payment method analysis
* Interactive filters
* Product and order data exploration
* Data tables
* Automated analytical insights

## Dataset

The application uses an apparel sales dataset containing:

* 116 sales line items
* 98 unique orders
* 12 products
* 4 payment methods
* Sales period: August 15, 2025 – October 7, 2025
* Total revenue: $11,214

## Technologies

* Google AI Studio
* React
* TypeScript
* Vite

## Repository

This repository contains the source code generated and refined in Google AI Studio.

The application was tested to verify that the main calculations, filters, and visualizations correspond to the source dataset.
